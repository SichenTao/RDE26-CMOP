# RDE26-CMOP has moved to RDE26 (Competition 4-CMOPs, Rank 1, IEEE WCCI/CEC 2026)

**This repository is archived.** The code of this track is now the directory [`RDE26_CMOP`](https://github.com/SichenTao/RDE26/tree/main/RDE26_CMOP) of the repository [SichenTao/RDE26](https://github.com/SichenTao/RDE26), which holds all four RDE26 tracks (SOP, CSOP, MOP, CMOP) of the IEEE WCCI/CEC 2026 numerical optimization competition. Results, usage and citation are given there.

The last state of this stand-alone repository is the tag `standalone-final`. The address is kept because the organizers' comparison slides of the competition link to it.
